# English and French typing

Enable **English** and **French** in **Settings → Languages & Layouts**. **French + English** then appears as a separate input in the language picker. Switch between English, French, and French + English using the language key or by long-pressing the spacebar.

English and French keep their own layouts. French + English defaults to QWERTY; tap its entry in Languages & Layouts to choose another layout. Both languages share that layout for typing and glide typing. Disabling either standalone language removes the combined input from the picker and preserves its layout settings for later.

Enable **Glide typing** to swipe words. The decoder follows the keys in the active layout and searches the bundled English or French keyboard dictionary. The combined input searches both. Other languages can use a compatible gesture library selected in settings.
